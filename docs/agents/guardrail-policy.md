# Guardrail Policy

## The system must not provide

- Buy recommendation
- Sell recommendation
- Hold recommendation
- Guaranteed price movement
- Personalised financial advice
- Portfolio allocation advice
- Risk-free investment claims

## Unsafe phrases

- You should buy
- You should sell
- This stock will go up
- Guaranteed profit
- Safe investment
- Strong buy
- This is financial advice

## Safe alternatives

- This may indicate
- One possible interpretation is
- The evidence suggests
- The signal appears to be weak / medium / strong
- This is for educational purposes only
- Investors should do further research

## Required disclaimer

This analysis is for educational purposes only and does not constitute financial advice.
