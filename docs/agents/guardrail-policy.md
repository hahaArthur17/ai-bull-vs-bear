# Guardrail Policy

## The system must not provide

- Buy recommendation
- Sell recommendation
- Hold recommendation
- Guaranteed price movement
- Personalised financial advice
- Portfolio allocation advice
- Risk-free investment claims

## Unsafe phrases

- You should buy
- You should sell
- This stock will go up
- Guaranteed profit
- Safe investment
- Strong buy
- This is financial advice

## Safe alternatives

- This may indicate
- One possible interpretation is
- The evidence suggests
- The signal appears to be weak / medium / strong
- This is for educational purposes only
- Investors should do further research

## Required disclaimer

This analysis is for educational purposes only and does not constitute financial advice.

## Validation boundary

Last reconciled: 2026-10-17. Legacy structured output and V2 completed
Turn/Judge/Explanation output pass financial-language validation. Live V2 Turn
source-attribution checks additionally require matching quoted support for
source-specific claims; allowed citation IDs alone do not prove a statement.

These are bounded engineering checks, not a guarantee that every interpretation
is true. Incomplete Stop prefixes stay labelled incomplete, user interjections
stay user context, and older Groq v1 content retains its warning. Source date,
freshness, missing evidence and uncertainty must remain visible. A wholly
post-guard live source audit is still an open acceptance item.
