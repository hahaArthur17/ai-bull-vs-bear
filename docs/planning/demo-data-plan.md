# Demo Data Plan

## Supported Stocks

- AAPL
- GOOG
- NVDA
- TSLA

## Stock Data

MVP will use cached daily OHLCV data for 3-6 months.

## News Data

MVP will use cached news headlines and summaries from free APIs, RSS feeds, or manually prepared demo data.

## Filing Evidence

MVP will use selected SEC filing excerpts, such as risk factors or business overview sections.

## Reason

Free APIs have request limits, so cached demo data will make the final demo stable.
