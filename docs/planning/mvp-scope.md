# MVP Scope

## Must Have

- User authentication
- Watchlist
- Stock detail page
- Cached stock data
- Technical indicators
- News and filing evidence
- RAG retrieval
- Bull Agent
- Bear Agent
- Judge Agent
- Evidence citations
- Financial advice guardrails

## Should Have

- Human-in-the-loop claim examination
- Explanation Agent
- Agent trace page
- Token ledger
- Analysis history

## Could Have

- Simulated streaming
- Scheduled data refresh
- Limited SEC filing parser

## Not in MVP

- Real-time stock trading data
- Buy/sell/hold recommendation
- Social media sentiment
- Full autonomous agent framework
- Large-scale web crawler
