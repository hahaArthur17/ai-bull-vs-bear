# User Stories

1. As a user, I want to search for a stock so that I can add it to my watchlist.

2. As a user, I want to view price movement and technical indicators so that I can understand recent market behaviour.

3. As a user, I want to see related news and filing evidence so that I know what information the AI uses.

4. As a user, I want to start a Bull vs Bear debate so that I can understand both positive and risk perspectives.

5. As a user, I want each AI claim to include evidence references so that I can trust the explanation.

6. As a user, I want to click a claim and ask what evidence supports it so that I can examine the AI's reasoning.

7. As a user, I want the system to avoid financial advice so that the app remains educational and safe.

8. As a developer, I want to log agent outputs and token usage so that I can debug and evaluate the system.
